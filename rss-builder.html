RSS 自定义订阅生成器

生成可自动更新的 RSS 订阅源配置 · 基于 GitHub Actions

1 粘贴网页源码

后端 Puppeteer 会根据此地址抓取最新内容，和 F12 结果一致
操作步骤：
  1. 在浏览器中打开目标网页
  2. 按 F12 打开开发者工具
  3. 切换到 Elements 标签
  4. 右键点击 <html> 标签 → Copy → Copy outerHTML
  5. 粘贴到下方文本框
源码长度: 0 字符

2 填写提取规则

语法： {%} 提取内容（按顺序编号为 {%1} {%2}...）， {*} 忽略内容（通配符）。
从F12源码中复制一段HTML结构，将要提取的部分替换为 {%}，可变部分替换为 {*}。
提取结果: 0 条，0 个字段

3 配置 RSS 订阅信息

二次抓取跳哪个网址？ 默认就是「列表页·条目链接模板」抓到的每条链接，你不用单独填二次跳转网址；只有列表链接和视频/图片页不是同一地址时，才填上面的「二次抓取地址模板」。
会不会抓错对应条目？ 每条目各自用自己的链接跳详情页，抓到的视频/图片天然属于该条目，不会串。
最终 RSS 输出字段（由你定义）：
· 标题 ← 条目标题模板　· 链接 ← 条目链接模板
· 视频 ← 二次抓取（可选）　· 封面 ← 二次抓取第 2 组（可选）
· 图片 ← 二次抓取（可选，多张=多条 <enclosure>）
后端逐个抓取详情页，把真实地址写入 RSS 的 <enclosure>；内容模板也可用 {video} / {poster} / {images} 令牌。
⚠️ 视频/图片直链由 GitHub Actions 后台抓取（浏览器受跨域限制无法在前端抓），保存后约 1-2 分钟才出现在 RSS。

4 生成 sources.json 配置

说明： 将生成的 JSON 内容复制到 GitHub 仓库的 sources.json 文件中，提交后 GitHub Actions 会自动生成 RSS。
点击「生成 sources.json」查看配置...
部署步骤：
  1. 将生成的 sources.json 内容复制到 GitHub 仓库的同名文件
  2. 提交更改，等待 GitHub Actions 自动执行
  3. 访问 RSS 链接：https://用户名.github.io/仓库名/feeds/feed-id.xml
